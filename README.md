# timoecu-timounu-open-firmware
Software architecture and source files for TimoEcu TimoUnu. Built using NXP RTD S32K3XX release 7.0.0 in S32 Design Studio. Development is done in a private repository along side the documentation detailing the development process, and then mirrored here for stable releases.

This is a project I have developed at UPB Drive Formula Student team.

You can learn more about TimoEcu at https://ocw.cs.pub.ro/courses/pm/prj2026/bianca.popa1106/timotei_iosif.cicu
